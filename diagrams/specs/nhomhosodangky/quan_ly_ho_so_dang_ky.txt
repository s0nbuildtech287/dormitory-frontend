Mô tả: Quản lý hồ sơ đăng ký (xem danh sách/chi tiết, nhập/import, tính điểm, xác thực ảnh, duyệt/từ chối, điều chỉnh trọng số, thống kê).
Tác nhân: Ban quản lý.
Các ràng buộc: Hồ sơ hợp lệ; cấu hình trọng số có sẵn; Vision API khả dụng.
Điều kiện kích hoạt: Admin mở mục Quản lý hồ sơ đăng ký.
Luồng sự kiện:
Luồng sự kiện chính:
1. Hệ thống hiển thị danh sách hồ sơ và các thao tác.
2. Actor chọn thao tác (nhập thủ công/import/xem chi tiết/duyệt/từ chối/xóa).
3. Hệ thống kiểm tra dữ liệu và cập nhật hồ sơ.
4. Hệ thống tính điểm xét duyệt tự động.
5. Hệ thống (hoặc admin kích hoạt) xác thực ảnh minh chứng.
6. Hệ thống cập nhật trạng thái hồ sơ.
7. Nếu hồ sơ được duyệt, hệ thống tự động tạo tài khoản sinh viên
	(email = email SV, mật khẩu = CCCD).
8. Hệ thống thông báo kết quả.
9. Hệ thống hiển thị thống kê hồ sơ.
Luồng rẽ nhánh:
2.a Import sai định dạng → thông báo lỗi.
4.a Thiếu dữ liệu → tính điểm không đầy đủ, gắn cảnh báo.
5.a Vision API lỗi → giữ trạng thái PENDING và thông báo lỗi.
6.a Admin điều chỉnh trọng số → hệ thống cập nhật và tính lại điểm.
6.b Duyệt/Từ chối thất bại → thông báo lỗi.
7.a Tạo tài khoản thất bại → thông báo lỗi và ghi log.
