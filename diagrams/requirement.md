✅ NHÓM XÁC THỰC (2)

1. Đăng nhập
   Nhập email + password
   Hệ thống kiểm tra
   Trả token + thông tin người dùng
2. Gửi OTP + Xác thực OTP + Đổi mật khẩu (gộp)
   Nhập email → gửi OTP
   Nhập OTP → xác thực
   Nhập mật khẩu mới → cập nhật
   ✅ NHÓM HỒ SƠ ĐĂNG KÝ (3)
3. Import hồ sơ từ Excel / Google Sheets
   Upload file hoặc nhập link Sheets
   Hệ thống đọc dữ liệu
   Lưu danh sách vào DB
4. Tính điểm hồ sơ + Xác thực ảnh Vision API
   Sau khi nộp → tính điểm theo quy định
   Admin có thể kích hoạt lại Vision API
   Cập nhật trạng thái ảnh
5. Duyệt / Từ chối hồ sơ + Điều chỉnh trọng số (gộp)
   Admin mở hồ sơ
   Duyệt hoặc từ chối
   Có thể chỉnh trọng số → tính lại điểm
   ✅ NHÓM PHÒNG & HỢP ĐỒNG (3)
6. Quản lý phòng (xem + thêm/sửa/xóa + cập nhật chỉ số)
   Admin xem danh sách phòng
   Thêm / sửa / xóa phòng
   Cập nhật chỉ số điện, nước
7. Tạo hợp đồng từ hồ sơ + Gán phòng + Kích hoạt
   Admin chọn hồ sơ đã duyệt
   Tạo hợp đồng
   Gán phòng → chuyển trạng thái Active
8. Chấm dứt hợp đồng
   Admin chọn hợp đồng
   Xác nhận chấm dứt
   Hệ thống cập nhật trạng thái
   ✅ NHÓM HÓA ĐƠN & THANH TOÁN (3)
9. Tạo hóa đơn từ chỉ số điện nước
   Admin nhập phòng + tháng + chỉ số
   Hệ thống tính tổng tiền
   Tạo hóa đơn
10. Sinh viên gửi số liệu điện nước + xem hóa đơn (gộp)
    Sinh viên nhập chỉ số (chỉ 1–5 đầu tháng)
    Hệ thống cập nhật hóa đơn
    Sinh viên xem danh sách hóa đơn
11. Thanh toán qua VNPay
    Sinh viên chọn hóa đơn
    Tạo link thanh toán
    VNPay callback IPN
    Hệ thống cập nhật trạng thái
    ✅ NHÓM PHẢN ÁNH (2)
12. Sinh viên gửi phản ánh + AI phân tích sentiment
    Sinh viên gửi phản ánh
    Hệ thống lưu + gọi AI phân tích
    Gắn nhãn cảm xúc / mức độ
13. Admin xử lý phản ánh (xem + phản hồi + xóa)
    Admin xem danh sách
    Cập nhật trạng thái / phản hồi
    Có thể xóa
    ✅ NHÓM THÔNG BÁO (1)
14. Tạo + Gửi thông báo (ALL / STUDENTS / SPECIFIC)
    Admin tạo nội dung
    Chọn nhóm nhận
    Hệ thống lưu & gửi
    ✅ NHÓM KỶ LUẬT (2)
15. Tạo phiếu kỷ luật + cập nhật điểm rèn luyện
    Admin tạo phiếu
    Hệ thống trừ điểm
    Lưu lịch sử
16. Sinh viên xem lịch sử kỷ luật
    Sinh viên đăng nhập
    Xem danh sách kỷ luật của mình
    ✅ NHÓM TÀI SẢN (1)
17. Quản lý tài sản (thêm/sửa/xóa + nhập kho + xuất kho)
    Admin thêm tài sản
    Nhập kho / xuất kho vào phòng
    Cập nhật tồn
    ✅ NHÓM SINH VIÊN – XEM THÔNG TIN (2)
18. Sinh viên xem thông tin cá nhân + hợp đồng
    Mở hồ sơ cá nhân
    Xem hợp đồng đang hiệu lực
19. Sinh viên xem thông báo + phản ánh lịch sử
    Xem thông báo
    Xem các phản ánh đã gửi
    ✅ NHÓM AI & LOG (1)
20. Chatbot AI (sinh viên hỏi + hệ thống trả lời)
    Sinh viên gửi câu hỏi
    AI trả lời dựa trên SYSTEM_PROMPT
    Trả kết quả
